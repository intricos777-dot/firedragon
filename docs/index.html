🐉 Firedragon Browser

Mozilla Firefox-based browser with Opera GX-style modules, music integration, and Pinterest theme support.

Modules

🎵 GX Music

Spotify / YouTube Music sidebar player with visualizer

🎬 GX Theater

Cinema mode, pop-out player, subtitle enhancement

⚡ GX Control

RAM / CPU monitor, network booster, background tab limiter

🧹 GX Cleaner

Cache, history, extension, and data cleanup

Quick Start

./launcher/firedragon

Extension Compatibility

python3 ext-compat/installer/convert.py extension.crx --install

Pinterest Themes

python3 ext-compat/installer/pinterest-theme.py "https://pinterest.com/username/board/"
